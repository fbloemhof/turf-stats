# Contributing to Turf Stats

## Commit messages
- **Always write commit messages in English**.
- Keep the subject line short and descriptive. Use a body when the change
  is non-trivial.

## Versioning, tags and releases
- Follow semantic versioning: `MAJOR.MINOR.PATCH`.
- **Git tags and GitHub releases are named exactly `vX.XX.X`** (e.g. `v1.20.0`).
  Do not use free-form names, dates, or prefixes other than the single `v`.

## Deploying
- Verify changes against a running site before claiming done.
